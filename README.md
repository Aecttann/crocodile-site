# Крокодил — сторінка конфіденційності

Публічна статична сторінка для посилань у Google Play та App Store:

**https://aecttann.github.io/crocodile-site/**

Сторінка не використовує JavaScript, аналітику, рекламу або зовнішні ресурси. Її текст потрібно оновлювати разом із локальним екраном `PrivacyScreen` у репозиторії застосунку, коли змінюється обробка даних.

GitHub Pages: гілка `main`, корінь репозиторію.
